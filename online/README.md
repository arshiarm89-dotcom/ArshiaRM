# موزه معاصر ایران (نسخه دیجیتال)

Created By ArshiaRM

موزه‌ی سه‌بعدی وسایل من: تالارهای ایران، منطقه و جهان، هر کدوم با معماری دوره‌ی خودش.

## دانلود برنامه‌ی اندروید

[دانلود Museum-ArshiaRM.apk](https://github.com/arshiarm89-dotcom/museum/releases/latest/download/Museum-ArshiaRM.apk)

برنامه خودش اعلان‌ها و وسیله‌های تازه رو آنلاین می‌گیره؛ لازم نیست هر بار دوباره نصبش کنی.

## فرستادن اعلان به همه (فقط صاحب موزه)

1. تب `Actions` رو باز کن.
2. از ستون سمت چپ «📢 فرستادن اعلان به همه» رو بزن.
3. دکمه‌ی `Run workflow` رو بزن، متن اعلان رو بنویس و دکمه‌ی سبز `Run workflow` رو بزن.

- برای رفتن به خط بعد، وسط متن علامت `|` بذار.
- برای پاک کردن اعلان فعلی، توی متن فقط بنویس: `پاک`
