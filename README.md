# موزه‌ی دیجیتال، کارگاه اپ اندروید (خصوصی)

Created By ArshiaRM

این مخزن خصوصیه و کلید امضای برنامه توشه. **هیچ‌وقت عمومیش نکن.**

## چی کجاست

| پوشه | چیه |
|---|---|
| `site/` | خود موزه: صفحه، عکس وسیله‌ها، آهنگ‌ها |
| `android/` | برنامه‌ی اندروید (نسخه‌ی ۲: اعلان و به‌روزرسانی آنلاین) |
| `online/` | چیزهایی که توی مخزن **عمومی** `museum` میرن: فرم اعلان، فهرست فایل‌ها |
| `tools/` | ابزار ساخت فهرست فایل‌ها (`manifest.json`) |

## چطور کار می‌کنه

- هر بار چیزی اینجا عوض بشه، گیت‌هاب خودش APK جدید می‌سازه (تب `Actions`).
- برنامه موقع باز شدن، مخزن عمومی `museum` رو نگاه می‌کنه:
  - اگه **اعلان** تازه باشه، یه بار برای هر کسی که برنامه رو داره نشون داده میشه.
  - اگه **وسیله یا آهنگ تازه** باشه، فقط همون فایل‌ها رو دانلود می‌کنه (اگه بیشتر از ۳ مگ باشه، اول می‌پرسه).
  - اگه **نسخه‌ی جدید خود برنامه** باشه (خیلی کم پیش میاد)، لینک دانلودش رو نشون میده.
- اگه اینترنت نباشه یا گیت‌هاب در دسترس نباشه، موزه با همون فایل‌های داخل برنامه کار می‌کنه.

## فرستادن اعلان (توی مخزن عمومی museum)

1. برو به تب `Actions` مخزن `museum`.
2. از ستون سمت چپ «📢 فرستادن اعلان به همه» رو بزن.
3. دکمه‌ی `Run workflow` رو بزن، متن اعلان رو بنویس و دکمه‌ی سبز `Run workflow` رو بزن.
4. حدود یه دقیقه بعد، هر کسی برنامه رو باز کنه اعلان رو می‌بینه.

- برای رفتن به خط بعد، وسط متن علامت `|` بذار.
- برای پاک کردن اعلان فعلی، توی متن فقط بنویس: `پاک`

## نکته‌ها

- فایل `android/app/museum.keystore` امضای برنامه‌ست. پاکش نکن، وگرنه نسخه‌های بعدی روی قبلی نصب نمیشن.
- عدد `appVersionCode` توی `android/app/build.gradle` فقط وقتی بالا میره که خود برنامه عوض بشه، نه وقتی وسیله اضافه میشه.
