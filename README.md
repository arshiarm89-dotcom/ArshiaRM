# موزه‌ی دیجیتال — اپ اندروید

Created By ArshiaRM

این پوشه پروژه‌ی اپ اندروید موزه‌ست. گیت‌هاب خودش ازش فایل APK می‌سازه؛ لازم نیست روی کامپیوترت چیزی نصب کنی.

## قدم به قدم

1. **حساب گیت‌هاب:** توی github.com ثبت‌نام کن (اگه حساب داری، وارد شو).
2. **مخزن جدید:** بالا سمت راست روی `+` و بعد `New repository` بزن.
   - اسمش رو بذار `museum`.
   - گزینه‌ی **Private** رو انتخاب کن (این‌طوری فقط خودت می‌بینیش).
   - روی `Create repository` بزن.
3. **آپلود فایل‌ها:** توی صفحه‌ی مخزن روی لینک `uploading an existing file` بزن.
   - همین پوشه رو روی کامپیوترت باز کن، **همه‌ی محتواش** رو انتخاب کن (Ctrl+A)، از جمله پوشه‌ی `.github`، و بکش بنداز توی صفحه‌ی آپلود.
   - خود پوشه رو نکش؛ محتوای داخلش رو بکش.
   - صبر کن همه آپلود بشن، بعد پایین صفحه روی `Commit changes` بزن.
4. **ساخته شدن APK:** برو توی تب `Actions`.
   - اگه پیغام فعال کردن Actions اومد، تأییدش کن.
   - یه کار به اسم `Build museum APK` شروع میشه (اگه شروع نشد، روش بزن و `Run workflow` رو بزن).
   - حدود ۵ تا ۱۰ دقیقه صبر کن تا تیک سبز بخوره.
5. **دانلود APK:** برگرد به صفحه‌ی اصلی مخزن. سمت راست، بخش `Releases` رو باز کن و روی `Museum-ArshiaRM.apk` بزن تا دانلود بشه.
6. **نصب روی گوشی:** فایل APK رو توی تلگرام برای خودت یا هر کی خواستی بفرست. روی گوشی اندرویدی بازش کن و نصب کن. اگه گوشی پرسید، اجازه‌ی «نصب از منابع ناشناس» رو بده.

## به‌روزرسانی

هر وقت موزه تغییر کرد، فقط فایل‌های جدید رو دوباره آپلود کن (جایگزین قبلی‌ها). یه APK جدید ساخته میشه که روی نسخه‌ی قبلی نصب میشه و لازم نیست اول پاکش کنی.

## نکته‌ها

- اپ فقط روی اندروید نصب میشه.
- همه‌ی موزه، عکس‌ها و آهنگ‌ها داخل خود اپه و بدون اینترنت هم کار می‌کنه.
- فایل `android/app/museum.keystore` امضای اپه. پاکش نکن، وگرنه نسخه‌های بعدی روی قبلی نصب نمیشن.
