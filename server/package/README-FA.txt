راهنمای نصب سرور موزه روی وی‌پی‌اس ویندوزی
Created By ArshiaRM

۱. با Remote Desktop به وی‌پی‌اس وصل شو.
۲. فایل MuseumServer.zip رو روی کامپیوتر خودت کپی کن (Ctrl+C) و روی دسکتاپ وی‌پی‌اس پیست کن (Ctrl+V).
۳. روی فایل zip راست‌کلیک کن و Extract All رو بزن.
۴. توی پوشه‌ای که باز شد، روی install.bat راست‌کلیک کن و Run as administrator رو بزن.
۵. چند ثانیه صبر کن. یه صفحه باز میشه که نوشته «سرور موزه روشنه ✅». تموم!

از این به بعد سرور خودش با روشن شدن وی‌پی‌اس روشن میشه و اگه به هر دلیلی بسته بشه، خودش دوباره راه میفته.

بعد از نصب:
- آدرس IP وی‌پی‌اس رو برای Claude بفرست تا برنامه‌ی گوشی بهش وصل بشه.
- هر کسی روی کامپیوتر آدرس http://IP-سرور:8085 رو توی مرورگر باز کنه، موزه رو می‌بینه و می‌تونه آنلاین بازدید کنه.
- اگه شرکت وی‌پی‌اس توی پنلش فایروال جدا داره، پورت 8085 (TCP) رو اونجا هم باز کن.

پاک کردن سرور: روی uninstall.bat راست‌کلیک کن و Run as administrator رو بزن.
گزارش کارهای سرور توی فایل C:\MuseumServer\server.log نوشته میشه.
